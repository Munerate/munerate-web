# munerate-web

**munerate** — Finance for intelligence.

Landing page with a liquid guilloché background rendered in WebGL2.
Next.js 15 · TypeScript · plain CSS · zero runtime dependencies beyond React.

```
npm install
npm run dev        # http://localhost:3000
npm run proto      # animation playground on http://localhost:4173/prototype/
```

Start with `CLAUDE.md`, then `docs/BRIEF.md`.
